# Step 5 output: validation errors, error bags and flash

Generated by `bun demo/step-5.ts`: one browser-like session against an Elysia 2 app, carrying the flash cookie between requests as the browser would. Request bodies are validated by the route's own `t.Object` schema:

```ts
			body: t.Object({
				name: t.String({ minLength: 2, error: 'Name is too short.' }),
				email: t.String({ format: 'email' }),
				address: t.Object({ city: t.String() })
			})
```
